CAPTURA APOYOS DIF V2 - ORDEN SIN RIESGO
Windows Server 2022 / IIS 10.x / SQL Server

PAQUETE FUSIONADO Y LISTO PARA EL SERVIDOR RECOPILADO EL 2026-10-15.
No use una copia anterior de 02_APLICATIVO_IIS.

1. SERVIDOR SQL
   Seguir 01_BASE_DATOS_SQLSERVER\LEEME_BASE_DATOS.md. Orden:
   00_PREVERIFICAR, respaldo verificado, 02_MIGRAR_ESQUEMA, catalogo y 04_VERIFICAR.

2. SERVIDOR APLICATIVO
   Copiar la nueva carpeta 02_APLICATIVO_IIS fuera de C:\inetpub.
   Confirmar en C:\inetpub\CapturaApoyosDIF\.env:
     PUBLIC_PREFIX=/CapturaApoyosDIF
   Seguir 02_APLICATIVO_IIS\LEEME_APLICATIVO.md y ejecutar ACTUALIZAR_IIS.ps1.
   El proceso respalda el codigo, conserva la configuracion y reinicia solo el pool
   CapturaApoyosDIF. No usa iisreset ni cambia dominio, bindings o certificado.

3. PRUEBA DE ACEPTACION
   Usar solamente documentos y datos ficticios. Confirmar:
   - superadmin: ve, exporta, elimina y administra;
   - capturista: captura y guarda, pero no ve registros ni exporta;
   - las fotos del OCR se procesan en memoria; las del formulario Datos de estructura
     se guardan en SQL Server por requerimiento funcional.

Si cualquier verificacion marca error, detenerse. No usar -AceptarBaseDistinta como
atajo; esa opcion solo procede despues de que Sistemas revise y fusione las diferencias.
